# Профили предметов (образец)

Скопируйте этот файл в `Кафедры.md` и ведите в нём свои предметы: состав работы,
блок `[настройки]` и особые требования преподавателя. `Кафедры.md` личный и в git
не попадает (см. `.gitignore`). Оформление делает `build.py` — в профиле только то,
чем предметы отличаются друг от друга.

## ПМ — курсовая работа

Состав: АННОТАЦИЯ, СОДЕРЖАНИЕ, ВВЕДЕНИЕ, разделы с подразделами, ЗАКЛЮЧЕНИЕ,
СПИСОК ИСТОЧНИКОВ, ПРИЛОЖЕНИЯ (при необходимости).

    [настройки]
    титул = да
    нумерация_страниц_с = ВВЕДЕНИЕ
    нумерация_объектов = по_разделам
    мин_источников = 5
    макс_источников = 7
    свежесть_источников = 5
    обязательно = АННОТАЦИЯ; СОДЕРЖАНИЕ; ВВЕДЕНИЕ; ЗАКЛЮЧЕНИЕ; СПИСОК ИСТОЧНИКОВ

Особое: во введении и заключении ссылок на источники нет; количество
и свежесть источников — по требованию руководителя.

## Практическая работа (пример: «Математическая статистика»)

Состав: титул; СОДЕРЖАНИЕ; 1 раздел по теме занятия — 1.1 Постановка задачи,
1.2 Ход выполнения работы (1.2.1, 1.2.2 …), 1.3 Выводы. Без введения и списка
источников.

    [настройки]
    титул = да
    нумерация_объектов = по_разделам
    имя_файла = ФамилияИО_ПРn
    обязательно = СОДЕРЖАНИЕ; Постановка задачи; Ход выполнения работы

Особое: данные — текстом или таблицей, не скриншотом; теория — формулами
со ссылками, все обозначения в «где»; графики 200 dpi без заголовка внутри.

## Отчёт по практике (титул + задание + рабочий график)

Состав: титул и бланки кафедры; АННОТАЦИЯ; СОДЕРЖАНИЕ; ВВЕДЕНИЕ; разделы;
ЗАКЛЮЧЕНИЕ; СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ; ПРИЛОЖЕНИЯ.

    [настройки]
    титул = 3
    нумерация_страниц_с = ВВЕДЕНИЕ
    нумерация_объектов = по_разделам
    мин_источников = 10
    объём = 40-60
    обязательно = АННОТАЦИЯ; СОДЕРЖАНИЕ; ВВЕДЕНИЕ; ЗАКЛЮЧЕНИЕ; СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ

Особое: `титул = 3` — три листа под титул, задание и рабочий график.
