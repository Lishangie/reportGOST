# Формат исходника report.md (сборщик 4.1)

`build.py` превращает исходник в .docx по нормоконтролю кафедры ПМ (РТУ МИРЭА).
Шрифты, интервалы, поля, стили, нумерация, ссылки, оглавление, разрывы таблиц
и вёрстка — его работа. В исходнике только структура и содержание. Состав
разделов — по профилю предмета (`Кафедры.md`): чего нет в файле, того нет в работе.
Что именно требует нормоконтроль и кто за что отвечает — `НОРМОКОНТРОЛЬ.md`.

## Настройки

Блок в начале файла, всё необязательно; в скобках — значение по умолчанию.

    [настройки]
    титул = да                      // да — страница под титул | нет | 3 — три страницы  (да)
    нумерация_объектов = по_разделам  // авто | по_разделам | сквозная  (авто)
    разделы_с_новой_страницы = нет  // (да)
    имя_файла = ФехАА_ПЗМС_ПР6       // имя готового .docx  (Отчёт)
    обязательно = СОДЕРЖАНИЕ; Постановка задачи; Ход выполнения работы
    нумерация_страниц_с = ВВЕДЕНИЕ  // (первый блок после аннотации/содержания)
    мин_источников = 5              // 0 — не проверять  (0)
    макс_источников = 7             // (0)
    свежесть_источников = 5         // не старше N лет; 0 — не проверять  (0)
    объём = 15-25                   // страниц, проверка  (нет)
    ширина_рисунков = 15            // по умолчанию, см  (12; в альбоме 24)
    рамка_рисунков = авто           // авто | да | нет: обводка рисунков на белом фоне
    обрезка_рисунков = да           // срезать белые поля картинок
    шапка_в_продолжении = да        // повторять шапку после «Продолжение Таблицы»  (да)
    pdf = да                        // сохранить ещё и PDF  (нет)
    вёрстка = авто                  // авто | word | libreoffice | нет

`обязательно` — заголовки, без которых скрипт выдаст замечание (сверка с профилем).

## Титульный лист

`титул = да` — первой идёт страница-заглушка, на её место вставляешь форму
вуза сам. Она считается в нумерации, но номер на ней не печатается.
Если к титулу прилагаются задание, рабочий график и т. п., укажи общее число
листов: `титул = 3` — будет три заглушки, и номера страниц в содержании
останутся верными после вставки настоящих листов.

## Заголовки

    # РАЗДЕЛ           уровень 1 (печатается прописными, номер «1»)
    ## Подраздел       уровень 2 («1.1»)
    ### Пункт          уровень 3 («1.1.1»), глубже нельзя
    # ЦЕЛЬ РАБОТЫ {-}  без номера

Без номера всегда: АННОТАЦИЯ, РЕФЕРАТ, СОДЕРЖАНИЕ, ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ,
ПРИЛОЖЕНИЯ/ПРИЛОЖЕНИЕ, «СПИСОК … ИСТОЧНИКОВ/ЛИТЕРАТУРЫ», ОПРЕДЕЛЕНИЯ,
ОБОЗНАЧЕНИЯ, ТЕРМИНЫ, ПЕРЕЧЕНЬ СОКРАЩЕНИЙ. Подразделы ненумерованного раздела
тоже без номера. Точка в конце заголовка убирается сама.

Сами заполняются: после СОДЕРЖАНИЕ — оглавление; после СПИСОК ИСТОЧНИКОВ —
список; после ПРИЛОЖЕНИЯ — перечень приложений.

Оглавление — настоящее поле Word (уровни 1–3, ссылки, номера страниц полями):
номера страниц проставлены и сверены с готовым документом, а если в Word нажать
«Обновить поле», оно пересоберётся таким же. АННОТАЦИЯ и само СОДЕРЖАНИЕ в него
не попадают.

Страницы: титул, задание, содержание считаются без номера; аннотация не
считается; номера видны с первого блока после содержания (по центру внизу, 11 пт).

## Текст

Абзац — строка (или несколько строк подряд); пустая строка разделяет абзацы.
Внутри: `**жирный**`, `*курсив*`, `` `код` ``, `$формула$`. Экранирование:
`\*`, `\$`, `\{`, `\}`.

Типографика сама: тире « — », кавычки «», минус перед числом (–5), неразрывные
пробелы (число+единица, инициалы, короткие слова, «№»), лишние пробелы перед
знаками препинания и внутри скобок и кавычек.

## Списки

    - маркированный пункт          (со строчной, «;», последний «.» — правится само)
      - вложенный (отступ 2 пробела)
    1. Нумерованный пункт.         (с прописной и с точкой — правится само)
       1.1. Вложенный нумерованный
    а) буквенный пункт             (буквы а, б, в, г, д, ж, и, к… — ставятся сами)

Каждый новый список нумеруется с 1. Маркер один на весь документ. Вложенные
пункты печатаются на том же отступе, что и основные (так в примерах нормоконтроля).
Смешанный список: под нумерованным пунктом — маркированные строки без отступа.

## Формулы

    [формула: id | LaTeX | пояснение 1; пояснение 2]
    [формула: | LaTeX]                          без номера

    [формула: ols | \hat{\beta} = (X^TX)^{-1}X^Ty | \hat{\beta} — вектор оценок; X — матрица плана]

Номер ставится, только если на формулу есть ссылка `{форм:id}` (так требует
нормоконтроль). Ссылка печатается в скобках: «по формуле (1.1)». До и после
формулы — пустая строка; затем «где» + каждое обозначение с новой строки,
обозначения сами становятся формулами, после формулы ставится запятая. Модуль
`|x|` — пишите `\|x\|` (вертикальная черта внутри блока экранируется); норма —
`\Vert`. Десятичная запятая в LaTeX: `0{,}05`.

Формула в строке: `$\bar{x} = 5{,}2$` — тоже редактор формул Word.

## Рисунки

    [рис: id | img/рис_1_1.png | Подпись без слова «Рисунок» | 15]

Ширина в см (необязательно; не больше 17, в альбоме 25). Белые поля срезаются,
картинке на белом фоне ставится тонкая обводка, слишком высокая уменьшается
(рисунок занимает не больше 75 % страницы). Нет файла — серая заглушка.
Подпись: «Рисунок 1.1 — …».

## Таблицы

    [табл: id | Название таблицы, ед. изм.]
    | Графа 1 | Графа 2 |
    | --- | --- |
    | значение | 1,25 |

Первая строка — шапка. Пустая ячейка или «-» — прочерк «—». Числа по центру,
текст слева. При переносе на новую страницу скрипт сам ставит «Продолжение
Таблицы 1.1» и снимает нижнюю линию. Таблица до 10 строк не разрывается, если
это не оставляет больше пяти пустых строк; первая и последняя строки одни
не остаются. `\|` — черта в ячейке.

## Листинги

    [листинг: id | code/model.py | Название листинга]
    [листинг: id | | Название | строки]      // номера строк 10, 20, 30…
    ```
    код прямо здесь
    ```

Код — из файла или из блока ``` сразу под меткой. Courier New 10 в рамке,
«Продолжение Листинга» при переносе. Больше ~45 строк — в приложение. Ссылка
на строки в тексте — в фигурных скобках: `\{30, 50\}`, `\{20-80\}`.

## Ссылки

    {рис:id}  {табл:id}  {лист:id}  {форм:id}  {прил:А}
    {ист:ключ}   {ист:ключ1, ключ2}   {ист:ключ, с. 21-25}

Подставляется номер — полем Word (перекрёстная ссылка). Слово пишется рядом
и с прописной: «на Рисунке {рис:id}», «в Таблице {табл:id}», «в Приложении
{прил:А}» (строчную скрипт исправит). Источники нумеруются по первому
упоминанию: `[1]`, `[1, 3]`, `[2-4]`, `[2, с. 21-25]`. Диапазон рисунков:
«на Рисунках {рис:a}–{рис:c}» засчитывает упоминание всех между ними.

## Приложения

    # ПРИЛОЖЕНИЯ
    [приложение: А | Название приложения]
    …
    [приложение: Б | Название]

Каждое с новой страницы: «Приложение А» по центру, ниже название. Нумерация
внутри: Рисунок А.1. Одно приложение — просто `# ПРИЛОЖЕНИЕ` и материал.

## Источники

В конце файла, по ГОСТ Р 7.0.5, порядок не важен (сортировка по упоминанию):

    [источники]
    box = Бокс Дж. Анализ временных рядов / Дж. Бокс. — Москва: Мир, 2017. — 406 с.
    fpp = Hyndman R. J. Forecasting. — URL: https://otexts.com/fpp3/ (дата обращения: 10.10.2026).

## Альбомные страницы

    [альбом]
    [рис: a0 | img/A0.png | Контекстная диаграмма A-0]
    [рис: a1 | img/A1.png | Декомпозиция A0]
    [/альбом]

Каждый рисунок — на своей альбомной странице (поля 2/2, сверху 3, снизу 1,
выравнивание по центру листа). Заголовок прямо перед `[альбом]` уходит на
альбомную страницу — тогда пустое место перед ней считается границей разделов
(до половины страницы). Текста внутри блока быть не должно.

## Прочее

`[разрыв]` — разрыв страницы.

## Что делает вёрстка (нужен Word или LibreOffice)

Скрипт собирает черновик, отдаёт Word (или LibreOffice, если Word нет), читает
PDF и правит сверху вниз, по одной правке за проход: «Продолжение
Таблицы/Листинга»; если рисунок не влез и внизу страницы осталось больше 5
пустых строк — уменьшает его (не больше чем на 30 %) или переносит перед ним
абзац, стоявший после. Абзац, который вводит следующий объект («… показано на
Рисунке 3.2»), не переносится. Чего не смог — пишет в «ВЁРСТКА» с номером
страницы и советом. В конце номера страниц оглавления сверяются с готовым PDF.

Документ для сдачи собирается на компьютере с Word: LibreOffice разбивает
страницы иначе, и вёрстка, сведённая в нём, в Word может разъехаться.

## Как писать, чтобы вёрстка сошлась

- Вывод по рисунку и фразу, вводящую следующий рисунок, — **разными абзацами**.
  Скрипт заполняет пустое место, перенося вывод перед рисунком; абзац со ссылкой
  на следующий объект он не трогает.
- После крупного рисунка — два-три коротких абзаца, а не один длинный.
- Замечание «внизу страницы пусто N строк — допишите текста хотя бы на K строк»:
  дописать нужно **перед тем объектом**, который открывает следующую страницу
  (в абзац перед ним или новым абзацем), либо уменьшить рисунок 4-м полем.
- «Свободно больше половины страницы перед «…»» — дописать вывод в конец
  предыдущего раздела на указанное число строк.
- Перед `[альбом]` ставь заголовок («## Модели процесса»): тогда страница перед
  альбомом — конец раздела и может быть заполнена наполовину.

## Что скрипт проверяет

Ссылка на объект до него, в абзаце рядом, со словом «Рисунок/Таблица»; два
объекта подряд; раздел кончается рисунком, таблицей или списком; «рис.», «ниже»,
«выше»; знаки «<», «=» в тексте без чисел; десятичная точка; несколько предложений
в пункте списка; раздел с одним подразделом; обязательные разделы; формула без
ссылки; приложения без ссылки или не по порядку, запрещённые буквы; источники
без ссылки/без описания, мало/много, старые, без «дата обращения», ссылки во
введении/заключении, ссылка после точки; «№ п/п», % в каждой строке; мутные
картинки (<140 dpi); длинные листинги; пустые места и полупустые страницы;
объём.
