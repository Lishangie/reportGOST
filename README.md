# Сборщик учебных отчётов по нормоконтролю (кафедра ПМ, РТУ МИРЭА)

Отчёт пишется обычным текстом в `report.md`, а `build.py` собирает из него
документ Word, оформленный по требованиям нормоконтроля: шрифты, поля, заголовки,
списки, подписи рисунков и таблиц, формулы в редакторе формул, перекрёстные
ссылки, автоматическое оглавление, «Продолжение таблицы», нумерация страниц,
приложения, список источников. После сборки скрипт сам проверяет вёрстку в Word
(пустые места внизу страниц, разрывы таблиц) и печатает список замечаний.

Текст отчёта обычно пишет ИИ-ассистент по правилам из `AGENTS.md`; сборка
работает и без него.

## Что нужно

- Windows с Microsoft Word (вёрстка проверяется в нём). Без Word сборщик
  использует LibreOffice, но страницы тот разбивает иначе.
- Python 3.10+ (при установке отметить «Add python.exe to PATH»).
- Библиотеки и pandoc `Собрать.bat` ставит сам при первом запуске
  (вручную: `python -m pip install -r requirements.txt`).

## Быстрый старт

1. Создать папку работы:
   `python build.py --init "D:\Учёба\Статистика\ПР1"` — появятся `report.md`,
   `img/`, `code/` и `Собрать.bat`.
2. Заполнить `report.md` (синтаксис — `ФОРМАТ.md`, образцы — `примеры/`),
   рисунки положить в `img/`.
3. Дважды щёлкнуть `Собрать.bat` в папке работы. Рядом появится .docx
   (и PDF, если в настройках `pdf = да`).
4. Исправить замечания из вывода и собрать ещё раз. Титульный лист вставить
   на место страницы-заглушки.

Проверка установки: перетащить `примеры\курсовая\report.md` на `Собрать.bat`.

## Работа с ИИ

- Агент с доступом к файлам (Antigravity, Cursor, Claude Code и т. п.):
  открыть эту папку как рабочую — правила он возьмёт из `AGENTS.md`.
- Чат без доступа к файлам: приложить `AGENTS.md`, `ФОРМАТ.md`, `Кафедры.md`
  и задание; ассистент вернёт `report.md`, вывод `Собрать.bat` отправлять ему
  текстом.

## Файлы

| Файл | Назначение |
| --- | --- |
| `build.py` | сборщик |
| `template.docx` | шаблон со стилями «… ПМ» |
| `Собрать.bat`, `Отладка.bat` | запуск; `Отладка.bat` сохраняет черновики вёрстки в `_отладка_вёрстки` |
| `ФОРМАТ.md` | синтаксис `report.md` |
| `НОРМОКОНТРОЛЬ.md` | требования и кто их выполняет |
| `AGENTS.md` | инструкция для ИИ (`CLAUDE.md`, `GEMINI.md` ссылаются на неё) |
| `Кафедры.пример.md` | образец профилей предметов: скопируйте в `Кафедры.md` (личный, в git не попадает) |
| `примеры/` | эталонные отчёты (курсовая и практическая) — образец синтаксиса |
| `Проверка.bat`, `check.py` | пересобирают примеры в Word; после любых правок сборщика должно быть «Всё чисто» |
| `_материалы/` | исходные материалы нормоконтроля (в git не попадают) |

## Ограничения

- Титульный лист и задание вставляются вручную: форма у каждого вуза своя.
- Вёрстка сводит пустые места автоматически не всегда: если рисунок не
  помещается, а переносить перед ним нечего, скрипт назовёт страницу — нужно
  дописать одно-два предложения.
- Оформление зашито под нормоконтроль кафедры ПМ РТУ МИРЭА; под другие
  требования нужно править стили в `template.docx` и константы в `build.py`.
